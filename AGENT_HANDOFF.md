## 2. What Command Nexus Actually Is (For the Copy)

Command Nexus is a **desktop AI governance and orchestration console** — not a chatbot, not a web app you rent monthly. It runs on your machine. You build AI agents inside it, give them instructions through a conversational "Book" system, deploy them to a live command center, and monitor everything they do in real time.

Key differentiator: **Other platforms let you *use* AI. Command Nexus lets you *command* it.**

## 3. The Five Parts (Feature Blocks for the Page)

### Part 1: Visibility Window (The Command Center)
- Live desktop viewport showing what your AI sees
- Real-time audit panes: Thought, Action, Planned Trajectory
- START / CANCEL mission control for dispatching AIs
- Task queue with status tracking
- Human approval gates for risky actions

**Copy angle:** *"See what your AI sees. Approve every risky move. You're still the general."*

### Part 2: AI Forge (The Builder)
- Character-sheet builder for custom AI agents
- Name, personality, use-case class, capabilities
- 7 use-case classes: Individual, Educational, Task-Ready, Business, Enterprise, All-Rounder, Military/Gov (locked)
- Save/load AI as JSON — portable, shareable, yours
- One-click deploy to Command Center

**Copy angle:** *"Build an AI in 60 seconds. Give it a name, a job, and a personality. Deploy it."*

### Part 3: The Book (The AI's Memory)
- Per-AI knowledge compendium — NOT global, not shared between AIs
- Tree-structured: Parts → Chapters → Sections
- Conversational Book AI dialog asks you 7 questions to build the AI's memory:
  1. What is this AI for?
  2. Who will it help?
  3. What instructions should it always follow?
  4. What should it ALWAYS remember? (persistent memory)
  5. What's current context that might change? (general memory)
  6. What are your preferences for how it interacts?
  7. What are its hard boundaries?
- AI never reveals its internal Book structure to users
- Rollback safety: any change can be reverted to defaults

**Copy angle:** *"Your AI remembers. Not in some black box you don't control — in a Book you write."*

### Part 4: Upgrades (Capability System)
- 24 capability modules across 12 categories
- 3 tiers per module: Lite (Low Resource), Standard (Medium), Pro (High)
- One main system resource bar (green → crimson red)
- Live RAM, CPU, disk monitoring
- Auto-blocks heavy activations if system would choke

**Copy angle:** *"24 skills. 3 power levels. One resource bar. No surprises."*

### Part 5: The Watcher (Background Defense)
- Always-on background AI, no UI, no pause button
- File integrity monitoring with SHA-256 baselines
- Scans every 5 seconds
- Alerts on unauthorized modifications

**Copy angle:** *"While you sleep, it watches."*

## 10. FAQ Suggestions (Answer These)

1. **Does this replace ChatGPT?** — No. It commands it. Use any backend you want.
2. **Does my data leave my computer?** — Not unless you configure it to. Default is 100% local.
3. **What AI backends work with it?** — Currently designed for local LLMs (Ollama, LM Studio) and API endpoints. Backend-agnostic architecture.
4. **Is it free?** — Core version is free. Advanced governance and multi-agent sync may be paid tiers later.
5. **Can I sell the AIs I build?** — Yes. They're JSON files. They're yours.
6. **Is this open source?** — Proprietary. See terms. (Update if this changes.)
7. **Will there be a Mac/Linux version?** — Windows first. Cross-platform is on the roadmap.
8. **What are the system requirements?** — Windows 10+, Python 3.10+, 4GB RAM minimum, 8GB recommended.
