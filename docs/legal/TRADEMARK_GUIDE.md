## 2. Proper Trademark Usage

### Always Do:
- Use the marks as adjectives, not nouns or verbs.
  - ✓ "The Command Nexus™ platform"
  - ✓ "Build AIs in the AI Forge™"
  - ✗ "Command Nexus your workflows" (verb)
  - ✗ "I use a Command Nexus" (noun, standalone)
- Distinguish the mark from surrounding text with **bold**, *italics*, or "quotation marks" on first use.
- Use the ™ symbol on first use in each document or page.
- Capitalize the marks exactly as shown.

### Never Do:
- Alter the marks: no abbreviations, no pluralization, no possessive forms.
  - ✗ "Command Nexuses" or "CN" (unless defined as an abbreviation)
  - ✗ "Command Nexus's features"
- Use the marks in a way that suggests endorsement, sponsorship, or affiliation without written permission.
- Register domain names, social media handles, or business names that incorporate the marks without authorization.
- Use the marks in connection with unlawful, defamatory, or infringing content.

## 3. Permitted Uses (Without Permission)

You may use the marks without prior written permission **only** for:

- **Accurate reference.** Describing the Software in reviews, tutorials, comparisons, or academic work, provided the usage is truthful and not misleading.
- **Compatibility statements.** "Compatible with Command Nexus™" or "Works with Command Nexus™," provided the statement is accurate and not confusing.
- **News reporting.** Journalistic or editorial use describing the product or company.

---

## 4. Prohibited Uses (Require Written Permission)

You may NOT use the marks without express written authorization for:

- **Product names.** Naming your own software, service, or product "Command Nexus [Something]" or "[Something] for Command Nexus."
- **Domain names.** Registering domains containing the marks (e.g., commandnexus-something.com).
- **Merchandise.** Printing the marks on merchandise for sale or distribution.
- **Social media.** Using the marks as profile names, page names, or handles that imply official affiliation.
- **Modified logos.** Creating derivative logos, icons, or stylized versions of the marks.
- **Open source projects.** Using the marks as the name of an open-source fork, plugin, or extension without approval.

## 8. International Considerations

Trademark rights are territorial. This guide is based on U.S. law. If distributing or marketing in other jurisdictions:
- Consult local counsel for trademark registration requirements.
- Use ™ for unregistered marks and ® only for marks registered in that specific country.
- Be aware of "first to file" vs. "first to use" jurisdictions.
