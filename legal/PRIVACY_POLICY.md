## 4. DATA STORAGE AND SECURITY

### 4.1 Local Data Storage
**Primary Data Location:**
All AI configurations, Books, audit logs, conversation history, and settings are stored **locally on your device** in:
```
~/.command_nexus/        (Linux/macOS)
%USERPROFILE%\.command_nexus\    (Windows)
```

**Data Format:**
- Configuration files stored as plain JSON (human-readable)
- User content stored in local SQLite database
- Not encrypted by default (users may implement their own encryption)

**Your Responsibility:**
- You are responsible for securing your local device and data
- We recommend implementing device-level encryption (BitLocker, FileVault, LUKS)
- Back up your local data regularly to prevent loss

### 4.2 Our Server Data Storage
The minimal data we collect is stored on secure servers with:
- Industry-standard encryption in transit (TLS 1.3+)
- Access controls and authentication requirements
- Regular security audits and monitoring
- Data retention limited to operational necessity

### 4.3 Security Measures
We employ the following security measures:
- **License Security:** HMAC-SHA256 cryptographic signing for license keys
- **Anti-Tampering:** Active protections against unauthorized Software modification
- **Secure Communications:** TLS encryption for all server communications
- **Access Control:** Restricted employee access to user data
- **Monitoring:** Continuous monitoring for security threats

**No security system is impenetrable.** While we strive to protect your information, we cannot guarantee absolute security.
