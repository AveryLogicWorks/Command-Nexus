Five Parts. One Command Center.

Visibility Window — The Command Center

Live desktop viewport showing what your AI sees. Real-time audit panes: Thought, Action, Planned Trajectory. START / CANCEL mission control. Task queue with status tracking. Human approval gates for risky actions.

"See what your AI sees. Approve every risky move. You're still the general."

AI Forge — The Builder

Character-sheet builder for custom AI agents. Name, personality, use-case class, capabilities. 7 use-case classes. Save/load AI as JSON — portable, shareable, yours. One-click deploy to Command Center.

"Build an AI in 60 seconds. Give it a name, a job, and a personality. Deploy it."

The Book — The AI's Memory

Per-AI knowledge compendium — not global, not shared between AIs. Tree-structured: Parts → Chapters → Sections. Conversational Book AI dialog asks you 7 questions to build the AI's memory. Rollback safety on every change.

"Your AI remembers. Not in some black box you don't control — in a Book you write."

Upgrades — Capability System

24 capability modules across 12 categories. 3 tiers per module: Lite, Standard, Pro. One main system resource bar (green → crimson red). Live RAM, CPU, disk monitoring. Auto-blocks heavy activations if system would choke.

"24 skills. 3 power levels. One resource bar. No surprises."

The Watcher — Background Defense

Always-on background AI, no UI, no pause button. File integrity monitoring with SHA-256 baselines. Scans every 5 seconds. Alerts on unauthorized modifications. Your silent guardian.

"While you sleep, it watches."

Frequently Asked Questions

Does this replace ChatGPT?
No. It commands it. Use any backend you want — local LLMs, API endpoints, or both.
Does my data leave my computer?
Not unless you configure it to. Default is 100% local. Your data, your hardware, your rules.
What AI backends work with it?
Currently designed for local LLMs (Ollama, LM Studio) and API endpoints. Backend-agnostic architecture — you choose.
Is it free?
There's a $10 one-time 15-day trial that unlocks every capability. Paid tiers start at $20/month. No subscription required to try it.
Can I sell the AIs I build?
Yes. They're JSON files. They're yours. Build them, share them, sell them.
Is this open source?
Proprietary. Command Nexus™ is a trademark of Avery Logic Works. See Terms of Use for details.
Will there be a Mac/Linux version?
Windows first. Cross-platform is on the roadmap.
What are the system requirements?
Windows 10+, 4GB RAM minimum, 8GB recommended. No installer required — just download and run the executable.
