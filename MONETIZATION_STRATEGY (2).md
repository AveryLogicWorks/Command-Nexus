## EXECUTIVE SUMMARY

Command Nexus is a **self-contained desktop software platform** that lets anyone create, govern, and operate fully custom AI agents **without writing code, without an internet connection, and without API keys.**

You pick what you want: capabilities, personality, rules, knowledge. The program builds the agent for you. It runs locally on your machine. Internet and API access are optional add-ons, not requirements.

**This is not a SaaS wrapper around someone else's API.** This is a professional software tool you install, own, and control — like Microsoft Office or Adobe Creative Suite, but for building AI agents.

**Pricing Philosophy:** A fraction of what custom agent development costs (typically $10K-$500K+ in consulting), while offering full local control, governance, and zero-dependency operation.

---

## WHAT COMMAND NEXUS ACTUALLY IS

### It Is:
- **A professional desktop software application** you install on your own computer
- **A visual agent builder** — point, click, choose capabilities, slide personality dials, define rules
- **A self-contained system** — runs offline, no internet required, no API keys needed
- **A governed execution environment** — safety gates, audit trails, approval workflows built in
- **Your property** — you own the agents you create, they run on your hardware

### It Is NOT:
- **A SaaS subscription** that calls someone else's API (like ChatGPT, Claude, etc.)
- **A developer framework** that requires Python, JavaScript, or any coding (like LangChain, AutoGen)
- **A consulting service** where you hire engineers to build agents for you
- **A cloud service** that stores your data on someone else's servers
- **An API wrapper** that charges you a markup on someone else's AI

### How You Build an Agent:
1. Open Command Nexus
2. Click "Create AI"
3. Pick a name, choose capabilities from checkboxes, slide personality sliders
4. Click "Talk to Book Keeper" and answer a few questions about what your AI should do
5. Click "Deploy"
6. Your agent is ready — no coding, no API setup, no internet needed

**This is why the pricing is software-license pricing, not API-usage pricing.**

## WHY THIS SEGREGATION WORKS

### 1. It Doesn't Punish Creativity
A student on the $50 Annual tier can write novels, generate images, and brainstorm just as well as an Unlimited tier user. The limitation is **how many AIs they can run at once**, not what those AIs can do creatively.

### 2. It Scales With Business Value
A freelancer who needs 4 specialized AIs (one for coding, one for writing, one for research, one for planning) pays $30/mo. A team that needs unlimited agents pays $80/mo. The price scales with **operational complexity**, not creative output.

### 3. It Makes Competitors Look Ridiculously Expensive
- "Why pay $20 for ONE ChatGPT when Nexus Starter gives you TWO fully custom governed agents for the same price?"
- "Why pay $50/month for Jasper when Nexus Annual gives you 5 agents for a full YEAR for $50?"

### 4. The Trial is a No-Brainer
- $10, one-time, 15 days — less than a pizza
- No credit card required for trial (optional)
- Users experience the full product before deciding
- 15 days is enough to build a real, working agent

### Phase 2: Enforcement Points

1. **AI Forge** — Check `max_active_ais` before creating/deploying new AIs
2. **Visibility Window** — Check `max_concurrent_sessions` before starting missions
3. **Capability Actions** — Check `allow_outward_actions` before enabling file write/export buttons
4. **Constraints Window** — Check `allowed_libraries` before showing module categories
5. **Audit Logger** — Auto-trim logs older than `audit_retention_days`
6. **Book Window** — Check tier before allowing export/handoff actions
7. **Owner Console** — Hide admin controls on Starter/Pro

### Phase 3: License Key System

- Starter: Free trial (7 days) → requires license key purchase
- Pro/Business: License key + online activation (monthly validation)
- Enterprise: Signed license file + on-premise deployment key

### Phase 4: Payment Integration (Future)

- Stripe for monthly/annual subscriptions
- Paddle or LemonSqueezy for international + tax handling
- Crypto payment option (aligns with privacy-first ethos)
